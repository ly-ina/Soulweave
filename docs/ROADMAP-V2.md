## 📝 Soulweave 进阶认知架构实施备忘录（V2）

目标：在五路召回基础上，引入“图扩散”与“动态情境势能（Context Momentum）”，构建具有真实惯性、能被行为触发、具备软边界回弹的认知系统。

### 一、 核心数据结构与基建

- **memory_links 表（图谱拓扑）**：`source_id, target_id, relation_type`（同源/共享词/因果）。不存静态权重。边只代表突触的物理连接，是否传递信号由当前的动态阻尼决定。
- **memory_metadata 表（隐形侧写）**：不动原记忆文本。独立记录特征信号（如 `["work", "intimacy"]`），用于计算情境势能。
- **日记索引化**：日记全文独立存储，`memory_links` 中只挂日记 ID 和摘要（懒加载，防 Token 爆炸）。

### 二、 动态情境势能系统（Context Momentum）

这是系统的“神经递质池”，决定图扩散的阻尼大小。

- **基础区间**：软下限 0.50（保证不瞎联想）到软上限 0.85（保证不忘教训）。
- **工作判定（拉高势能）**：1 分钟内工具调用累计 > 30 秒 且 次数 ≥ 2 次，势能 +0.08。
- **亲密判定（降低势能）**：1 分钟内无重度工作，且触发“亲密词”（如抱抱、贴贴），势能 -0.15。
- **覆写机制**：若降低后立刻又进入重度工作，立刻取消降低倾向，回拉势能。
- **软边界回弹（关键）**：允许势能因为极端的连续工作或极度亲密，短暂突破 0.85 或 0.50。但如果没有持续刺激，系统会按轮次缓慢回弹（如每轮回归 0.02），直到回到软边界内。
- **压缩重置**：触发“上下文压缩”时，强制将势能重置到 0.60（稳定基线），清零历史累加，让状态重新开始漂移。

### 三、 第六路召回：图扩散（PPR）

- **算法**：Personalized PageRank。纯 JS 迭代，最多 2 跳。
- **阻尼应用**：扩散时的阻尼系数 α 直接映射当前势能。势能越高（0.85），α 越大（保守，专注工作）；势能越低（0.50），α 越小（发散，联想闲聊）。
- **角色**：第六路结果权重压低（RRF 融合占比约 0.15），只作为“惊喜联想”补充，不抢占主力召回。

### 四、 黄金测试集验证

- 用当前的 600 条记忆和几十篇日记进行测试。
- 验证目标：输入特定词，看扩散能否精准捞出那天挂载的散碎记忆；检查有无“孤岛”（边建少了）或“枢纽污染”（高频词吸走信号）。

### 五、 中长期防坑（数据量 6000+）

- **枢纽惩罚**：PPR 扩散时除以节点度数，防高频词污染。
- **清理弱边**：压缩上下文时，顺手删除 weight < 0.1 的弱边。
- **死守 2 跳**：绝不扩散到第 3 跳，防止逻辑断裂。
