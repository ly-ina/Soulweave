# 魂汐（Hunxi）：写入零模型，读出才用模型

> 2026-11-27 定名。作者与讨论：伊纳 / 蓝汐。
> 状态：设计已定、未动代码。落地顺序见文末。

---

## 1. 原则

**写入路径零模型，读出路径才用模型。**

索引不需要人格，人格只在「想起」和「说话」时出现。

这条边界的好处是工程性的，不是美学性的：

| 好处 | 说明 |
|---|---|
| 可重跑 | 换分词器/换参数重建索引，结果可对比 |
| 可复现 | 出问题能定位到具体规则，不是「上次模型心情不一样」 |
| 可离线 | 写入不占对话轮次，可以批量、可以夜间跑 |
| 零依赖 | 不引入模型文件与推理 runtime，与项目「运行时零依赖」一致 |

类比：Git 的写入是内容寻址、确定性的；只有人读的时候才有解释。

**第二条约束（2026-11-27 加）：新增的魂汐层尽量不量化。**

阻尼、势能机已经量化的部分保留不动；此后新加的判断用**资格、集合关系、字典序**，不用分数和阈值。

理由：阈值是脆的（换语料就失效）、分数不可复述（说得出 0.83，说不出为什么）、加权求和会把「错」平均掉。

具体替代：

| 量化做法 | 非量化替代 |
|---|---|
| 阈值判定 | 资格：有 / 没有 |
| 加权求和 | 字典序：先房间、再锚、再时间 |
| 相似度分数 | 集合关系：同房 / 共享锚 / 有边 |
| 命中率百分比 | 错法清单：哪条错、错在哪 |

**排序用字典序，不用总分。** 先按房间筛，房间内按锚筛，都平了再看时间。没有权重这个东西。

## 2. 架构：原文不做遗忘

**原文库 append-only，永远只增不减。容量不是瓶颈，索引才是。**

```
frag（原文，无限增长）
  │  质量门：这段让「世界模型」变化了吗？
  ▼
summary（定位器，不是替代品）
  │  关键词提取 + 记忆矩阵归一
  ▼
kw（有限）+ kw_link（共现边）
  │
  ▼
检索 / 激活 ──> 输出 ──> 新的 frag（闭环）
```

**有限性来自准入，不来自遗忘。** kw 层之所以有限，是因为它只从「值得出摘要」的原文里长出来。质量门是有限性的来源。

工具调用不进原文库，这是原文增长慢于轮次的原因之一。

### 保底路径

质量门不能是硬丢弃：

- 出了 summary 的 frag → 走索引，快路径
- 没出 summary 的 frag → 仍可被 BM25 直接命中，慢路径

门判错了不会真丢东西，只是走慢路。**门的误判率可以直接观测**（慢路径命中占比）。

---

## 3. 摘要 = 定位器，不是短版原文

因为原文永久保留，summary 的正确职责是**一条能唯一指回原文的指纹**：

```
这件事是什么（抽取句） + 涉及哪些关键词 + 大概什么时候 + frag 范围
```

不需要复述细节——细节在 frag 里，一条 SQL 就取回。

这个定义把「摘要好不好」从主观问题变成了客观问题：

> **给一条 summary，能不能唯一找回它的原文？**
> 能 = 合格；不能 = 太糊。

**完全自动，不需要人评。** 这是整个设计里最关键的一步：需求降级让技术难度和评估难度同时降级。

## 4. 记忆矩阵：回到向量模型的源头

共现矩阵 + PPMI 就是 LSA / GloVe 的数学基础。向量模型本来就是从这里长出来的，只是后来用神经网络隐式化了。

在本项目场景里，显式矩阵更合适：

| 维度 | 显式共现矩阵 | 通用向量模型 |
|---|---|---|
| 可解释 | 每一维是真实词 | 黑箱 |
| 增量更新 | 加一行一列 | 重训/微调 |
| 领域适应 | 自动（就是本项目语料） | 通用先验未必贴 |
| 依赖 | 零 | 模型文件 + runtime |

规模红利：6 272 个词，全对全余弦 `6272² / 2 ≈ 2 000 万`次稀疏点积，平均度 5.4——JS 毫秒级。**不需要降维、不需要 ANN**。

弱点：低频词共现不足、相似度噪声大。与激活条件互补——低频词本来就不该单独当种子。

### 判据是矩阵的投影，不是独立词表

房间判据不单独维护，它是记忆矩阵的一个**投影**：

```
frag × term 共现矩阵
  → 房间 = 矩阵上的一个方向（一组稳定共现的项）
  → 判据 = 该方向的项 profile：稳定只出现在这间房 frag 里的项
  → 落房 = 新 frag 的项集与哪间 profile 重叠最多（集合关系，不算分）
```

所以自进化不是「培养新词」这个额外动作：矩阵长出新共现，profile 自己变；共现散了，项自然掉出去。手写种子在这里没有位置——最多是冷启动时的一次性脚手架，且必须能被投影覆盖。

> 2026-11-27 修正：此前 `core/tree/grow.mjs` 从证据句抽词、培养房间触发词，方向是反的——它把「文本里出现的词」当判据来源。判据来源只能是矩阵。

### 自进化

- **新词发现**：凝固度（内部互信息）+ 左右熵（边界自由度），攒够自动进候选词表。
- **同义合并**：行向量余弦超阈值 → 合并到高频词，低频留作别名。

词表是长出来的，不是维护出来的。

### 防漂移

- 边权重设上限
- 权重更新带时间衰减（与「时间惩罚」同一机制，用在写路径）
- 每次重建索引时对矩阵整体归一化，不做增量叠加

## 5. 管线（全是经典算法，零模型）

```
frag
 ├─ 1. 分词 + 分句
 ├─ 2. 话题切段   TextTiling（词法衔接度突变点）—— 不是定长硬切
 ├─ 3. 段内抽句   MMR（相关性 − 冗余度）
 ├─ 4. 提关键词   TF-IDF + 记忆矩阵归一
 └─ 5. 新颖度门   新 kw 组合够不够新
        ↓
     summary = 抽取句 + kw 骨架 + 时间 + frag 范围
```

**质量门是矩阵的副产品，不用单独设计**：新 frag 先用矩阵算与已有片段的覆盖率——
高度重叠 → 补充/确认，不出摘要；命中多个不同区域 → 新组合，值得出。

## 6. 激活条件：命中 ≠ 激活

> 2026-11-27 晚修订：判据改为「跨房词不许单独开门」，并新增房间体系与丘脑，见 §10。

**激活是门，不是分数。** 权重错一点只是排序差，门错了是压根不该醒的被叫醒。

### 背景词 vs 情景词

**判据已改为房间区分（2026-11-27 晚）：一个词出现在多个房间 → 跨房词 → 不许单独开门；只出现在一个房间 → 该房间的情景词。**
这是纯集合判断，没有比例。下面的时间覆盖率数据作为佐证保留。

实测（2026-11-27，语料 41 天，8 018 条 summary）：

| 词 | df | 出现天数 | 覆盖率 | 情景强度 |
|---|---|---|---|---|
| 小汐 | 3 013 | 41 | 100% | 0.000 |
| 今天 | 143 | 39 | 95% | 0.049 |
| 看看 | 189 | 37 | 90% | 0.098 |
| 更新 | 102 | 33 | 80% | 0.195 |
| 重启 | 224 | 31 | 76% | 0.244 |
| 记忆 | 120 | 29 | 71% | 0.293 |
| 压缩 | 159 | 28 | 68% | 0.317 |
| 伊纳 | 245 | 19 | 46% | 0.537 |
| （对照）回电 | 3 | 2 | 5% | 0.951 |
| （对照）装作 | 3 | 2 | 5% | 0.951 |
| （对照）加密 | 11 | 3 | 7% | 0.927 |

**0.35 与 0.68 之间几乎没有重叠。** 这是自然形成的分界，不用调参。

### 门

```
激活 = (≥1 个情景词命中)
     OR (≥2 个不同背景词同时命中)        ← 关系类：「小汐 + 伊纳」
     OR (1 个背景词 + 1 个情景词)

单个背景词命中 → 只当过滤条件，永不触发
```

好处：超级 hub 不需要被「惩罚」，只是**没有资格单独开门**。惩罚是猜它不重要，门是确认它不构成证据。

而且自适应：语料变长后，「今天/看看」会自动降级，「重启/压缩」若变成日常会自动升格，新词从 0.95 起步自己归位。**不用维护 stopword 表。**

注意：`df < 5` 的词不参与覆盖率计算，直接当低频情景词；门槛等语料到 90 天再定死。

## 7. 怎么判断好不好：案例集，不是指标

不做命中率。做**案例集**：20–30 条真实查询，每条记三样——

```
查询原文
该召回什么（具体到哪条记忆/哪段对话）
该不该跨房 —— 该跨的话是哪条桥
```

跑完逐条看错在哪，产出**错法清单**：

| 错法 | 指向 |
|---|---|
| 房间错 | 阶段 1（房间 + 跨区） |
| 召回了不该召的（跨区乱跑） | 阶段 1 / 7 |
| 该召的没召到 | 阶段 4（质量门）或阶段 3（摘要太糊） |
| 想起来的是同一件老事 | 阶段 8（inhibition of return） |

同样的思路贯穿单条校验：

- **摘要**：只看 fingerprint，能不能唯一指向一条原文？指不到 = 太糊。
- **切分**：这段是一件事还是两件事？
- **质量门**：这次放行/拦截，能用一句话解释吗？解释不出 = 判据错了。
- **共现网络**：抽 20 对词，说得出该不该像吗？

## 8. 风险

1. **中文分词是唯一硬依赖。** 分词烂，后面全废。需要自带词频词典 + 最大匹配 + 未登录词走新词发现。纯数据文件，不违反零依赖。
2. **抽取式摘要读起来不像人话。** 不需要——它只做定位器。
3. **闭环自我强化**（回音室）。同一 kw 最近 N 轮刚命中过的下一轮降权（inhibition of return），时间惩罚跑稳后再加。
4. **早期覆盖率不稳。** 用「天」不用「条」已缓解；样本少时门槛别写死。

## 11. 自进化是核心，不是附加项

**魂汐的重点不是五间房，是判据会自己长。** 房间只是骨架，长出来的投影才是肉。

这条贯彻整条链：

| 层 | 长什么 | 状态 |
|---|---|---|
| 原文级矩阵 | `frag × term` 共现 | ⬜ 第一刀（现有 `kw_link` 只连 summary） |
| 房间判据 | 矩阵投影的项 profile | ⬜ 重写：`grow.mjs` 方向反了 |
| 词表 | 新词（凝固度 + 左右熵） | 🟡 `appendLearned` 有壳无电 |
| 共现网络 | 边的显著性与权重 | 🟡 有权重无归一 |
| 摘要在项目里的职责 | 定位器形态 | ⬜ |

### 为什么必须自进化

写死的判据只能覆盖设计时想到的表达。真实对话里同一件事有无数种说法——「重启」「重开」「reload」「拉起来」。词表补不完。但补不完的词不是靠「培养」补，而是靠矩阵自己长：新共现出现，profile 自动更新。

### 唯一的铁律

**判据必须挂在矩阵上。**

- **无投影不判**：新 frag 先落底座房（情景房）；要进别的房，必须有矩阵里已有的项支撑。没有就是没有。
- **跨房项不进 profile**：一个项在多间房稳定出现，就不属于任何一间，从所有 profile 里排除。
- **复现不是条件**：复现次数既是分子又是分母，语料越大它自己就涨，等于没设门槛（2026-11-27 伊纳）。条件只设在两处：情景条件满足、关联独占。
- **撤销是重算，不是动作**：profile 是算出来的派生数据。矩阵一变，重算即撤销，不需要单独维护撤销逻辑。

四条都不是阈值，是资格判断。这也是「不量化」的另一面：靠的是「在哪些房出现过」这种集合关系，不是学习率、阈值、权重衰减。

### 房间语义（2026-11-27 修正）

| 房间 | 记忆类型 | 判据形态 | **不是** |
|---|---|---|---|
| 情景房 | 自传体事件 | 时间 + 人 + 经过 | 不是「含时间词」 |
| 空间房 | 位置/指向/路径（存储型，最廉价） | 位置关系：A 在 B 内、从 A 到 B、指向 C | 不是「字符串长得像路径」 |
| 程序房 | 习惯/程序性记忆/动作选择（训练型） | 重复出现的做法序列：遇到 X 就 Y、先 A 再 B | 不是代码、不是命令行 |
| 执行房 | 规则/边界/承诺 | 约束 + 它约束的对象 | 不是「含必须/不许」 |
| 显著房 | 情绪标记/在意 | 情绪项 + 挂在哪件事上 | 不是「含怕/喜欢」 |

结构判据（正则）只用于冷启动时落第一版投影，跑完就退场——它是过程，不是判据本身。

### 稳定层：性格的载体（2026-11-27 定）

soul 初始化只是**初始条件**，不是性格载体。能自增长、能影响性格的，只有后续的稳定层。

| 规则 | 内容 | 防什么 |
|---|---|---|
| **不积累，只重算** | 稳定层不是写出来的，是定期从原文**全量重导** | 增量叠加 → 漂移不可回溯、撤销无从下手 |
| **原子是冲突** | 存「冲突 → 裁决 → 后来有没有被推翻」，不存形容词 | 攒成一份描述，而不是排序 |
| **双口注入** | 同时接判据（什么被注意）和读出（怎么说） | 只接读出是戏服，只接判据是暗箱 |
| **单向分离** | 稳定层可以影响「什么被注意」，不能影响「什么能进稳定层」 | 自己出题自己判卷 → 自证循环 |

**性格是排序，不是集合。**

soul 的定位随之收窄：它是偏置，不参与日常重算，只在两种情况下被拉出来质询——跨房判断长期打架，或慢层漂移超过阈值。平时它不说话，只压低或抬高某些东西的权重。

稳定层成立还有三个前置条件，缺一条就只能长成镜子：

1. **两个时间尺度**：快层（这次对话的情绪/上下文）与慢层分开更新，慢层不跟着快层走。
2. **选择要留下代价**：投影必须接上「召回 → 人的反应 → 重算」，否则没有选择压力。
3. **定期从原文重算**：防止判据吃自己的投影、越吃越窄。
