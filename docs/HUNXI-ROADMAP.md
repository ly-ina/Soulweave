## 一、整体流程（目标形态）

```
                         ┌──────────────────────────────────────────┐
                         │            写入路径 · 零模型              │
                         └──────────────────────────────────────────┘

  对话原文
     │
     ▼
 ┌────────┐   ① 分句 + 分词（已有 terms.mjs）
 │  frag  │   ② 话题切段（TextTiling，替代定长 500 字）
 │ 原文库 │   ③ 抽取句（MMR：相关性 − 冗余）
 └───┬────┘   ④ kw 骨架（TF-IDF + 矩阵归一）
     │        ⑤ 新颖度门（新 kw 组合够不够新）
     │              │
     │        不够新 ─┴─> 只留 frag，走 BM25 慢路径
     │              │
     │           够新
     │              ▼
     │        ┌──────────┐   fingerprint = 抽取句 + kw 骨架 + 时间 + frag 范围
     │        │ summary  │   职责：唯一指回原文，不复述细节
     │        └────┬─────┘
     │             │
     │             ▼
     │      ┌─────────────┐   词表自进化：新词发现 → appendLearned
     │      │ kw / kw_link│   同义合并：行向量余弦 → 归一
     │      │  记忆矩阵   │   防漂移：权重上限 + 时间衰减 + 重建归一
     │      └──────┬──────┘
     │             │
     └─────────────┼──────────────────────────────────┐
                   │                                  │
                   ▼                                  │
         ┌───────────────────┐                        │
         │ 读出路径 · 用模型 │                        │
         │  ① 查询分词       │                        │
         │  ② 激活门         │  单个背景词不激活       │
         │  ③ seeds 扩散     │  1–2 跳，hub 设顶       │
         │  ④ 取回 frag      │                        │
         │  ⑤ 小汐想起并输出 │                        │
         └─────────┬─────────┘                        │
                   │                                  │
                   └────────── 输出写回 frag ──────────┘
                              （闭环）
```

**唯一需要模型的地方是 ⑤**：想起记忆之后怎么说话。

## 三、每阶段细则

### 阶段 0 · 度量（第一个动手的）

**为什么先做**：整条链已经在跑（`extractive-v1`），缺的不是实现是秤。

**产物**：`tools/hunxi-audit.mjs`，纯只读，不改库。

**四条指标，全部自动**：

| 指标 | 怎么量 | 期望 |
|---|---|---|
| 摘要可定位率 | summary 的高 idf 词做 query → 能否命中它自己的 frag | > 95% |
| 关键词自召回率 | summary 的 kw 做 query → 能否召回自己 | > 90% |
| 摘要信噪比 | 无新 kw + 极短 + 与高频词高度重叠的 summary 占比 | 越低越好，先看基线 |
| 切段对齐度 | 一条 summary 的句子来自几个不同 frag | 越少越好 |

**跑完立刻能决定下一刀切哪**：
- 可定位率低 → 阶段 1
- 信噪比差 → 阶段 3
- 自召回高但整体召回差 → 阶段 6

---

### 阶段 1 · 切分

**问题**：现在 `splitFragments(max:500, overlap:80)` 定长切；`summary` 按 turn 切。两处都不是「一件事」。

**做法**：TextTiling——用相邻段落的词法衔接度找突变点。

**验收**：抽 50 条 summary，人工看「是否只讲一件事」，≥40 条通过。

**风险**：短对话切不出来（少于 3 轮的话题）。保底：切不出来就整段作为一段。

---

### 阶段 2 · 摘要器改成定位器

**现在**：抽 1–3 句，≤220 字，定位不清。

**改成**：

```
fingerprint = {
  抽取句      : MMR 选出的 1–3 句（原文逐字，不改写）
  kw 骨架     : 3–8 个词，按 idf 排序
  时间        : t
  frag 范围   : [frag_id ...]（写进 frag_summary，已存在）
}
```

**验收**：可定位率 > 95%（阶段 0 的指标）。

**风险**：抽取式读起来不像人话——不需要，它只做定位器。

---

### 阶段 3 · 质量门

**判据**：这段原文带来的新 kw 组合够不够新。

```
novelty = 1 - (已有片段对该 kw 组合的覆盖率)
novelty < 阈值 → 不出 summary（不是丢弃 frag）
```

**保底**：没出 summary 的 frag 必须仍可被 BM25 直接命中。

**验收**：
- 噪声 summary 占比下降
- 慢路径命中占比可观测（这是门的误判率）

---

### 阶段 4 · 词表自进化

**现状**：`appendLearned` 写好了，**全仓库零调用**；`lexicon-learned.txt` 14 个词是手写的。

**做法**：
1. **新词发现**：凝固度（内部互信息）+ 左右熵（边界自由度）→ 候选词
2. 候选过 `appendLearned` 进词表
3. **同义合并**：行向量余弦 > 阈值 → 合并到高频词，低频留别名

**验收**：连续跑 1 000 条 frag，新词自动入库，人工抽查 ≥70% 是真词。

---

### 阶段 5 · 记忆矩阵

**现状**：`kw_link` 有权重（0.86–38.6），不是 PPMI，压不住高频词。

**做法**：
- 权重换 PPMI（正点互信息）
- 防漂移三约束：边权重上限 / 时间衰减 / 重建时整体归一

**规模红利**：6 272 词全对全余弦 ≈ 2 000 万次稀疏点积，JS 毫秒级，**不需要 ANN、不需要降维**。

**验收**：随机抽 20 对词看相似度，≥16 对符合直觉。

---

### 阶段 6 · 激活门

**现状**：`retrieve.mjs` 纯打分，命中即算。

**做法**：

1. `kw` 加 `day_cov` 派生列（出现天数 / 语料总天数）
2. 拆 `seeds`（情景词）与 `filters`（背景词）
3. 门：

```
激活 = (≥1 情景词)
     OR (≥2 不同背景词)
     OR (1 背景 + 1 情景)
单个背景词 → 只过滤，不激活
```

**实测依据**（41 天语料）：背景词情景强度 0.00–0.35，情景词 0.68–0.95，中间几乎无重叠。

**验收**：
- 单背景词命中不产生注入
- 回音室指标：同一 kw 连续 N 轮被命中的比例

---

### 阶段 7 · 读出闭环

**做法**：
- 召回 → 输出 → 输出写回 frag → 自动进阶段 1
- inhibition of return：同一 kw 最近 N 轮刚命中的，下轮降权
- momentum 接线：`prestep` 每轮 `observe`；`assocByPPR` 传 `alpha`；compaction 喂 `compacted`

**验收**：整环无人值守跑通，连续 3 天不出现回音室。

## 四、明确不做

| 不做 | 原因 |
|---|---|
| 遗忘 / 删除层 | 原文 append-only；有限性来自准入，不来自删除 |
| 向量模型 / embedding | 规模小，显式矩阵够用且可解释 |
| ANN / HNSW 索引 | 6 272 词暴力算毫秒级 |
| 让模型参与写入 | 违反魂汐原则，失去可重跑性 |

**例外**：若阶段 2 的可定位率长期上不去，可以考虑「句子级向量」只做补召回（`summary_vec` 表已存在），但不进主链路。
